Release policy

Each production merge requires passing CI, financial integrity tests, data preservation checks, security review, deployment readiness and explicit owner approval.

A draft PR is never merge-ready. Merged code is not automatically counted as deployed.

Data boundaries

This public website exposes only pre-approved package identifiers, generic descriptions, safe status summaries and a verification timestamp. Private PR descriptions, code, reviews, logs, financial records and credentials stay private.

Automatic refresh

The GitHub Action requests a refresh every 15 minutes and supports manual runs. GitHub schedules may be delayed. This page displays the last published snapshot; refreshing the browser does not run GitHub Actions.
